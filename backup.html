데이터 전체 백업

Firebase(Firestore·Realtime Database)와 선택한 구글 시트의 데이터를 모두 내려받아 하나의 ZIP 파일로 저장합니다. 프로그램별 엑셀과 원본 JSON이 함께 들어갑니다. 저장할 때 SharePoint 동기화 폴더를 선택하세요.

1. 연결 설정

최초 설정 방법 (한 번만)
  1. Google Cloud Console에서 기존 Firebase 프로젝트 하나(예: jnfam-ledger)를 선택합니다.
  2. APIs & Services → Library에서 다음 API를 사용 설정합니다: Cloud Firestore API, Firebase Management API, Firebase Realtime Database Management API, Google Drive API.
  3. OAuth consent screen: User type External, 앱 이름 "JNFAM Backup", 테스트 사용자에 본인 Gmail을 추가합니다.
  4. Credentials → Create credentials → OAuth client ID: 유형 Web application, Authorized JavaScript origins에 https://yt9495.github.io 추가.
  5. 만들어진 Client ID를 위 칸에 붙여넣고 저장합니다. 로그인 시 "확인되지 않은 앱" 경고가 나오면 고급 → 계속을 누르면 됩니다.

2. 로그인

Firebase 프로젝트 소유 계정으로 로그인하세요. 읽기 권한만 요청합니다.

3. 백업 대상

Firebase 프로젝트
로그인하면 자동으로 불러옵니다.
구글 시트 (포함할 시트만 체크, 선택은 저장됩니다)
로그인하면 자동으로 불러옵니다.

4. 백업 실행

파일 이름: JNFAM_Backup_YYYY-MM-DD.zip. 크롬·엣지에서는 저장 위치를 직접 고를 수 있고, 다음부터 같은 폴더가 기본으로 열립니다. 개인정보(급여·휴가·출퇴근)가 포함되므로 회사 지정 폴더에만 저장하세요.
